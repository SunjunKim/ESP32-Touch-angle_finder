# 중앙 기준면 위치 비교

## 최종 범위: β≤0

사용자 추가 조건으로 양수 β는 최종 비교에서 제외했다. 높이 58.5 mm에서 β=0,−3,−8,−15°의 최대 절대 오차는 각각 0,1.10914,3.42555,7.45099°이며 RMS는 0,0.39464,1.24054,2.76711°이다. 중앙 기준점에서는 모두 정확하고 최대치는 칼끝에서 발생한다. β=−8°에서 높이 20,58.5,120 mm의 최대 오차는 4.56656,3.42555,3.03274°이다. 12개 설정×1001개 위치 검증을 통과했다. 아래 양수 β 예시는 범위 변경 이전 기록이다.

`node simulation/reference_placement.cjs`로 재계산한다. `node tests/reference_placement_test.cjs`로 기준점 영점과 기하 정답을 검증한다.

조건: 최신 중앙 직선/칼끝 2차 곡선, 길이 200 mm, 중앙 피벗 수평거리 180 mm, 오프셋 0 mm, 칼과 피벗 설정 후 고정, 접촉 위치 50%에서 1회 기준 저장. 측정기는 스톤 연마면과 평행하며 칼면 기준시 긴 축을 중앙 접선의 수직 방향으로 둔다. 센서는 이상적/정적이며 시간 경로, 잡음, 바이어스, 장착 오차는 포함하지 않는다.

가속도 best-effort는 부호 있는 전체 기울기 `t(g)=sign(gx)*atan2(hypot(gx,gy),gz)`의 차이다. 칼면 기준은 현재 t에서 중앙 칼면 t를 빼고 예각으로 환산하여 실제 연마각 α와 비교한다. 중앙 스톤 기준은 현재 t에서 중앙 스톤 t를 빼서 부호 있는 실제 변화량 α−α중앙과 비교한다. 이는 특정 알고리즘의 오차이며 가속도 알고리즘 전체의 최적 성능 한계가 아니다. 스톤 기준만으로 칼면의 절대 연마각은 제공하지 않는다.

피벗 높이 58.5 mm, 1001개 위치에서 최대 절대 오차(두 측정 대상 각각): β=−8°는 3.42555°, β=0°는 수치 정밀도 내 0°, β=+8°는 1.74960°. 두 경우는 중앙에서 정확하므로 이 조건에서는 오차가 동일하다. +8°에서는 실제 각도가 커지는데 스톤 기준 추정 변화량은 음수가 될 수 있다.

별개의 물리량: 중앙 스톤 법선 N0와 현재 법선 N 사이의 3D 평면각은 `atan2(|N0×N|,|N0·N|)`이다. β=8°, 높이 58.5 mm, 칼끝에서 실제 연마각 변화 +1.46924°지만 3D 평면각은 10.40519°이다. 이것을 변화량으로 해석하면 이상적인 자세 추적이어도 +8.93594° 차이가 난다. 실제 펌웨어의 plane_angle은 이 3D 평면각 정의다. 이 보고서는 펌웨어 필터를 실행한 결과가 아니다.

자이로를 적분하지 않고 정지 판정에만 쓰면 정적 기하 오차는 위와 같다. 이상적인 완전 자세 추적은 칼면 기준 3D 연마각을 정확하게 복원하지만, 실제 6축 센서의 시간 누적 오차는 위 정적 시뮬레이션으로 평가하지 않았다. 피벗 높이나 β를 바꾸면 기준을 다시 잡는다.
