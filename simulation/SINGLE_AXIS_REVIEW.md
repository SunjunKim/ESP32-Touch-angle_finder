# 단축 기준면 조건 재검토

## 고정 조건

- 각 측정 시나리오에서 칼/클램프/피벗 위치와 방향은 불변.
- 중앙 칼날 접선은 수평. 기준면은 그 접선을 회전축으로 한 각도 β만큼 기울어진다. 두 번째 회전축은 없음.
- 영점 측정기의 긴 축은 중앙 접선에 수직. 영점 가속도는 지정한 좌표계에서 `(sinβ,0,cosβ)`.
- 스톤 연마면은 현재 칼날 접선을 포함하지만 폭 축이 접선과 같다는 가정은 없음.
- 봉은 고정 피벗 통과. 스톤/측정기는 봉을 따라 왕복할 수 있음.
- 설치 기울기 슬라이더 변경은 별도 설치와 재영점을 뜻하며, 같은 시나리오의 시간 중 기구 회전을 뜻하지 않음.

펌웨어 및 라이브러리 변경/업로드 없음. 이번 변경은 독립 시뮬레이션과 테스트, 보고서뿐이다.

## 모델 확대

200 mm 예시 칼날의 높이를 `-25+50s^p`로 표현하며 p=2,4,6을 비교했다. 실제 제품/실제 칼의 스캔이 아닌 합성 곡선이다.

- 피벗의 중앙 칼날 접선 수직 거리: 140,180,240 mm.
- 중앙의 실제 연마각: 12,18,25°.
- 봉 축과 연마면 사이 거리 h: 0,10 mm. 실제 장비 측정값이 아니라 민감도 시험값.
- 기준 경사 β: -15,-8,-3,0,3,8,15°.
- 칼날 위치: 0~100%, 101개.
- 총 38,178 자세. 각 자세는 정지/이상 가속도 관측.

칼면 법선 B, 접선 T, 칼면 안의 법선 U=B×T, V=P-E라 할 때:

    α = atan2(V·B, V·U) - asin(h / hypot(V·B,V·U))
    N = B cosα - U sinα
    X = normalize(V - h N)
    Y = N × X

따라서 봉/연마면 오프셋을 넣어도 T·N=0, X·N=0 및 P-E=hN+dX를 만족한다. 중앙 높이를 `D tanα0 + h/cosα0`로 정해 중앙 목표각을 유지한다.

별도로 직선 자 모델(p=0) 505 자세와 스톤 전후 위치(-50~-20~0~20~50 mm)의 정지 가속도를 확인했다. 왕복 운동가속도/진동과 센서 노이즈는 이번 계산에 넣지 않았다. 실제 왕복 중 가속도를 제거했다는 의미가 아니다.

## 비교한 센서 전용 계산식

축: x=스톤 긴 축, y=폭 축, z=연마면 법선. 실제 보드에는 장착 좌표/부호 변환이 선행되어야 한다.

정규화된 가속도 g, 기준 측정 g0에 대해:

    β = atan2(g0x, g0z)                 # 부호를 보존
    θ = atan2(hypot(gx,gy),gz)
    θ_signed = sign(gx) θ

1. 이전 비교식: `acute(θ - |β|)` — 부호 없는 기준 경사. **음의 기준 경사에서 잘못된 값**.
2. 부호 보존 면 기울기: `acute(θ_signed - β)`.
3. 긴 축 투영: `acute(atan2(gx,gz) - β)`.
4. 두 중력 벡터 사이 각도: `atan2(|g0×g|,g0·g)`.

여기서 acute는 면 사이 무부호 각도로 0~90°에 접는 연산이다. 4번은 각 벡터가 서로 다른 측정기 좌표계에 있다는 점을 무시하는 후보식이며 물리적으로 일반적인 상대각 공식이 아니다.

추정 함수에는 칼 곡선, 접선, 접촉 위치, 피벗 치수, 실제 α를 전달하지 않았다.

수평 기준면, 직선 자, 중앙 접촉의 이상 모델에서는 부호 보존 면 기울기가 각각 정답과 일치했다. 긴 축 투영식과 벡터 각도식은 직선 자에서 봉 방향이 변하는 것만으로도 오류가 생길 수 있어 일반 대체식으로 채택하지 않는다.

## 동일 센서 관측의 반례 — 최신 제한 내

두 경우 모두 β=8°, 중앙 접선 수평, 중앙 실제 각도18°, D=180 mm, h=0이고 각 시나리오 동안 기구는 고정이다. 중앙 접촉점을 원점으로 맞추면 두 경우의 피벗 위치도 일치한다.

- A: p=4, rise=50 mm, s=0.9 → 실제17.941723846°.
- B: p=8, rise=34.530627685 mm, s=0.823017561 → 실제17.530360409°.

두 경우의 영점 가속도:

    g0 = (0.13917310096006544, 0, 0.9902680687415704)

현재 가속도는 1e-10 g 이내에서 같음:

    g = (0.4225346822189139, -0.05619753322945881, 0.9046028297441289)

두 경우 모두 정지 자이로는 0인데 실제 각도 차이는 0.411363438°다. 즉 **칼 형상과 접촉 위치를 모르는 범용 센서 전용 정지 계산식**은 단축 기준 조건만으로 둘을 구별할 수 없다. 이는 동일한 특정 칼의 위치 추정 가능성까지 부정하는 것이 아니다. 형상/치수를 사전에 입력하면 별도 역기구학 모델을 사용할 수 있으나 이번 센서 전용 방식과는 다른 조건이다.

## 제안하는 설정과 보류 사항

### ACC-only

- 기존 6면 보정 유지.
- 기준에서 폭 축 가속도가 0에 가까운지 확인해 중앙 접선 수평 정렬을 검사한다. 긴 축 방향/실제 중앙 위치는 사용자 절차로 보장해야 한다.
- 기준 경사의 부호를 보존하는 면 기울기식을 기본 **근사 후보**로 삼는다.
- 수평 기준면 외에는 `APPROX` 표시. 결과를 실제 각도의 보장값으로 표시하지 않는다.
- `gx≈0`이며 수평 가속도 성분이 유의한 경우 부호 분기 불안정 경고. 현재 코드의 0.01g 조건은 설명용 초안이며 큰 오차를 모두 검출한다는 보장이 없다.
- 사용자 목표 허용오차를 만족하는지 실기 비교 전에는 최종 펌웨어 알고리즘으로 확정하지 않는다.

### ACC+GYRO, 누적 오차 경로 없음

- 위 근사각은 가속도로만 계산. 각속도를 각도로 적분하지 않는다.
- 정지 바이어스 보정 후 자이로를 영점/각도 확정 판정에만 추가한다.
- 자이로 잔여 바이어스는 판정에 영향을 줄 수 있으나, 각도 적분 드리프트는 없다.
- 10,000회 동일 입력 호출에서 출력 불변 확인. 수평 상태의 중력축 회전(가속도 방향 불변)도 자이로는 검출한다.
- 기하 오차는 ACC-only와 동일. 이 방식이 기울어진 기준면의 방향 정보를 복원하지는 않는다.
