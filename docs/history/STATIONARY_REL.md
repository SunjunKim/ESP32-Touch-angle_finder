# 정지 측정 REL — 단일 영점 UX

> Superseded: current accelerometer-only main-based implementation is documented in ../ACCEL_REL.md. This file is historical.

## 현재 조작 (2026-09-07 UX 개정)

최신 센서/정지 판정 조정은 [IMU_TUNING.md](IMU_TUNING.md)에 기록한다. 기존 1.2초 고정 바이어스 임계값 대신 0.8초 변동 기반 판정과 히스테리시스를 사용하며, 가속도/자이로 LPF 대역폭은 약 3Hz다.

단일 영점 및 이동 빨강/정지 하양 버전 빌드·업로드·해시 검증 완료. 프로그램 1,290,671 bytes, 정적 RAM 160,672 bytes. 기존/추가 ASan·UBSan 테스트 통과. 업로드 후 `stationary-15s-20260907-220210.jsonl`에서 정상 부팅 및 초기 `gaps=0` 확인. 실제 버튼 카운트다운·색 전환·기준면 왕복 정확도는 사용자 실기 확인이 남아 있다.

기존과 같이 하단의 큰 영점 버튼 하나를 사용한다. 기존 6면 CAL 절차와 저장 데이터는 유지한다.

1. 측정기의 바닥면을 원하는 기준 평면에 밀착한다. 칼면 또는 스톤 모두 가능하다.
2. `Hold 3s to set zero`를 3초 누른다. 카운트다운 후 `Release to set zero`가 표시되면 손을 뗀다.
3. 필터가 안정된 뒤 약 0.8–1.6초 정지한다. 성공하면 확인음과 `0.0° / Ref: SET / Static`을 표시한다.
4. 측정기로 대상 평면을 측정한다. 별도의 중앙 확인은 없다. 이동 중에는 현재 각도 추정값을 **빨강**, 정지 판정 후 보정된 각도를 **하양**으로 표시한다. 기준이 없거나 추적 손실/센서 데이터가 200ms 이상 오래된 경우에만 `--`를 표시한다.
5. 다시 영점을 잡을 때는 같은 버튼을 3초 누른다. `Tracking lost`가 나오면 **원래 기준 평면으로 돌아가서** 다시 영점을 잡는다. 측정 중인 스톤에서 누르면 그 스톤이 새 기준이 된다.

영점 수집 순간 접촉면 법선 `(0,0,1)`을 직접 저장하고 이후 자이로로 운반한다. 기준면 중력 경사는 `atan2(hypot(up.x,up.y),up.z)`로 저장하므로 ±0.5° 부호 제한이나 한 축 정렬 검사가 없다. 기준면은 측정 중 고정돼 있어야 한다. 칼/클램프를 회전하거나 저장한 기준 스톤을 움직였다면 새 기준이 필요하다. 스톤 장착면과 연마면은 평행해야 한다.

정지 판정 전 빨간 값은 마지막 정지 바이어스로 자이로를 실시간 적분한 미확정 추정값이다. 정지하면 별도의 법선 상태에서 이동 전후 바이어스로 재계산하고 중력 제약을 적용해 흰색 값으로 교체하므로 값이 보정될 수 있다. 빨간 미리보기는 최종 재적분의 시작값으로 사용하지 않는다. 8초 이동 버퍼/드리프트 예산/샘플 공백 안전 처리는 유지하며, 자동 중앙 재설정은 하지 않는다. 칼면→스톤으로 옮기는 이동도 추적 구간과 오차 예산에 포함된다. 결과는 부호 있는 스칼라 경사 차이가 아니라 두 평면 사이 예각이다.

검증: 단일 Zero에 대해 양·음 경사(±30°, ±0.51°, 0°), 비중앙 자세, 역방향 이동 및 재영점 45개 조합, 7–30° 회전과 45° yaw의 120개 조합을 기존 회귀 테스트에 추가했다. 이전 두 단계 알고리즘의 시뮬레이션 수치를 새 방식의 정확도 보장으로 인용하면 안 된다. 신규 방식의 실기 검증은 아래 역사 기록과 별개로 수행한다.

## 아래는 이전 두 단계 구현과 진단의 역사 기록 (현재 조작 아님)

## 조작

1. 기존 CAL 6면 보정을 완료한다. 절차/면 순서/수집 방식은 유지했다.
2. 클램프 중앙 칼면에 측정기를 올린다. 긴 축은 칼등/중앙 접선에 수직, 화면은 위로. `Blade ref: hold 3s`를 누르고 손을 떼어 정지한다. 버튼 요청 이후 새 1.2초 구간으로 경사 β를 저장한다.
3. 측정기를 스톤의 연마면과 평행한 장착면에 고정한다. 스톤을 칼날 중앙 50%에 접촉시켜 `Center 50%: confirm`을 누른 뒤 정지한다. 이 확인은 사용자가 실제 중앙 위치와 방향을 보증하는 동작이다. 센서가 중앙 위치를 자동 검출하지 않는다.
4. 이동 중 값은 `--`. 멈추고 약 1.2–2.4초 기다리면 칼면 대비 실제 연마각을 0.1° 단위로 표시한다.
5. `Return to 50%`가 나오면 중앙 복귀 후 확인한다. 칼/클램프 β를 바꾸거나 칼을 뒤집으면 2부터 다시 수행한다. 피벗 높이 조절/측정기 탈착 후에도 중앙 확인을 다시 하는 것이 안전하다.

β 범위는 −30°~0°를 대상으로 한다(기준 정렬 오차 허용으로 +0.5°까지 입력 수용). 칼등 축과 중앙 칼날 접선은 평행/수평이어야 한다. 스톤 폭축과 접선의 평행 조건은 중앙에서만 사용한다. 곡선 구간에서는 강제하지 않는다. 장착면이 연마면과 평행하지 않으면 별도 장착 오차가 발생한다.

## 계산

- 입력은 기존 앱 가속도 좌표계(수평 −Z). 추적기 내부 중력 상향 벡터는 `up = −normalize(accel)`이다.
- 가속도 보정의 축 부호/장착 회전을 자이로에도 적용한다. 축반사 시 각속도의 pseudovector 부호를 반영하고, 가속도 scale 크기는 자이로에 적용하지 않는다.
- 중앙 칼면에서 β=atan2(up.x,up.z). 중앙 스톤 확인 시 `n=cosβ up − sinβ normalize(up×(0,−1,0))`로 센서 좌표계 칼면 법선을 초기화한다.
- 이동 구간을 보관하고 정지 후 바이어스를 새로 측정한다. 이동 전·후 정지 평균의 시간 중심을 고려한 선형 보간 바이어스로 각속도를 다시 적분한다. 마지막 확인된 정지 구간은 적분에서 제외한다.
- 정지 가속도 평균으로 `n·up=cosβ` 제약을 적용한다. 방향(yaw)은 관측되지 않으므로 그대로 유지한다.
- 출력은 `atan2(hypot(nx,ny),abs(nz))`. 두 스톤 면 사이 각도가 아니라 칼면과 스톤 연마면 사이 예각이다.

## 제한과 실패 처리

- IMU 작업 주기 약 12ms를 목표로 짧은 INT 대기시간을 사용한다. USB 진단은 1Hz `REL_V3` 출력. 라이브러리 내부 변경 없음.
- 1.2초 정지 판정: 가속도 크기 ±0.08g, 구간 가속도 변화 ≤0.003g, 자이로 변화 ≤0.22°/s, 평균제거 gyro RMS <0.10°/s, 기존 바이어스 대비 순간 속도 <0.20°/s 등. 최초 바이어스와 재확인은 사용자의 정지 확인이 필요하다. 매우 느린 일정 회전을 IMU만으로 완전히 구분하지 못한다.
- 최대 8초 또는 2048샘플(약 32KB)의 제한된 버퍼. 초과/50ms 이상의 샘플 공백/비정상 입력/950°/s 이상이면 추적 무효화, 칼면 β는 보존하고 중앙 확인을 요구한다.
- 표시는 새 데이터가 200ms 이내이며 정지/추적 유효일 때만 제공한다. 숫자가 안정돼 보여도 절대 정확도를 보장하는 것은 아니다.
- 드리프트 관리 예산은 이동시간 t에 대해 `|sinβ| (0.05t+0.01t²)`도 누적, 0.30° 초과 시 중앙 확인 요구. 측정으로 보증된 신뢰구간이 아니라 보수적으로 조정해야 하는 초기 엔지니어링 설정이다. 가속도 절대오차/장착오차는 포함하지 않는다.
- 정지 시 바이어스 갱신은 누적 yaw를 지우지 않는다. 중앙 확인만 방향 기준을 복구한다. β, 기준, 바이어스는 전원 재시작 시 재설정한다.

## 실기 검증 요청

### 정지 중 표시 소실: USB 진단 전송 대기 수정

첫 중앙 측정에서 사용자 화면 `14.2 / Static`과 43초간 유효 로그(14.138–14.195°)를 확인했다. 이후 시리얼 수집 종료 뒤 표시가 사라졌고, 재접속 로그 `stationary-60s-20260907-214746.jsonl` 첫 샘플에서 dt=1.3101s, status=5를 확인했다. 50ms 초과 공백은 정상적인 안전 처리로 추적을 무효화하며 중앙 재확인 전 자동 복구하지 않는다.

앱의 IMU 작업에서 직접 실행하던 USB printf가 호스트 수신 중단 시 대기 가능한 구조였다. 라이브러리 수정 없이 USB 전송 timeout=0, 초기 TX 버퍼 1024 bytes, 진단 행의 전체 용량 확인 후 전송(부족 시 생략)으로 변경했다. `gaps`(50ms 초과 샘플 수), `maxdt`(최대 샘플 간격), `drop`(생략/불완전 진단 수)를 추가했다. 안전 판정 임계값은 완화하지 않았다. 시리얼 닫기/재열기 실기 검증은 이 수정의 재업로드 후 수행한다.

수정 빌드/업로드/해시 확인 완료. ASan/UBSan 회귀 테스트 통과. 21:51:32의 15초 수집 종료 후 30초 이상 시리얼을 닫고 21:52:28 재접속했다. `gaps=0 maxdt=0.0167` 유지, `drop=1→37`로 진단을 생략하면서 IMU 샘플링은 계속됨을 확인했다. 이 시험은 기준 설정 대기 구간이므로 실제 연마각의 장시간 유지 시험을 대신하지 않는다. 재접속 로그 말미에서 칼면 기준 β=−11.407°, status=1을 확인했으며 중앙 확인과 물리적 기준면 일치 여부는 사용자 검증이 필요하다.

2026-09-07 사용자 요청으로 동일 타겟을 재빌드하고 `/dev/cu.usbmodem143301`에 업로드했다. 쓰기 해시 검증과 재시작 성공, 부팅 후 `REL_V3` 로그와 `status=0`(칼면 기준 대기)을 확인했다. 전체 플래시 삭제는 하지 않았으며 NVS 영역은 쓰기 대상에서 제외됐다. 기존 보정 데이터의 실제 로드 여부 및 측정 정확도는 아직 실기 확인 전이다. 위 빌드 기록의 “아직 업로드하지 않았다”는 최초 빌드 시점 기록이다.

먼저 β=0에서 중앙/75%/칼끝 정지값, 이후 β≈−8°에서 같은 위치와 중앙 왕복을 독립 기준각과 비교해야 한다. 캘리브레이션 데이터 읽기, 버튼/문구 배치, 60초 정지 유지, 이동 중 `--`, 중앙 복귀 정합을 확인한다. 느린 이동에서 정지 오인 및 실제 손떨림에 따른 대기시간도 확인해야 한다.
