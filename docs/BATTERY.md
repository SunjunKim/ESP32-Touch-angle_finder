# 배터리 표시

숫자는 평활화된 배터리 전압만 소수 둘째 자리까지 표시한다(예: `3.85V`).
아이콘의 채움 레벨은 정격 3.7V / 만충 4.2V 단셀 리튬폴리머(Li-Po)의 비선형 전압 룩업 테이블을
선형 보간한 추정 잔량을 표시한다. 3.50V=0%, 3.70V=10%, 3.85V=50%,
4.00V=80%, 4.10V=90%, 4.20V=100%다. 0%는 기존 3.5V 종료 기준에
맞춘 기기 사용 가능 잔량이며, 셀의 화학적 완전 방전을 뜻하지 않는다.
기존 ADC 환산 계수와 전압 평활화(1초 주기, alpha=0.15)는 유지한다.

이 테이블은 일반적인 곡선의 근사값이며 특정 셀의 실측 데이터나 공인된
범용 SOC 함수가 아니다. 충전/방전 모두 전압에 따라 갱신하되, 충전 전류에
의한 전압 상승은 아래의 고정 보정값으로만 근사하며 부하·온도·노화 오차를
정확히 보정할 수 없다. 100%도 충전 완료
신호가 아니다. 정확도를 높이려면 사용 셀과 부하에서 전압–용량을 측정해
`src/battery_soc.h`를 보정하거나 전류 측정 가능한 fuel gauge를 추가한다.
방법과 한계: [TI 전압 기반 SOC 추정](https://www.ti.com/lit/an/sluaaa1/sluaaa1.pdf).

[회로도 V2.1](hardware/ESP32-S3-Touch-LCD-1.69_V2.1.pdf)의 U9 ETA6098 STAT(9번 핀)은 미연결이다. 데이터시트에
따르면 충전 중 LOW, 완료 시 high-impedance지만 MCU에서 읽을 수 없다.
정확한 충전 상태 감지에는 STAT를 MCU의 사용 가능한 GPIO에 적절한
3.3V 풀업과 함께 연결하는 하드웨어 변경이 필요하다.

현재는 전압 변화로 plug/unplug를 추정하는 휴리스틱을 적용한다.
USB 호스트 연결(`HWCDC::isPlugged()`) 또는 전압 기반 연결 추정 시
배터리 내부에 투명 배경의 흰색 번개를 겹쳐 표시한다.
충전 표시 중에는 추정 SOC 95% 이상이면 녹색, 95% 미만이면 회색으로
채움·테두리·단자·전압 글자를 표시한다. 번개는 흰색을 유지한다.
두 연결 조건 모두 없으면 번개를 숨긴다.
USB 호스트 감지는 시리얼 모니터를 열지 않아도 동작하며 약 1초마다 갱신한다.
충전기·보조배터리·충전 전용 케이블 및 USB suspend 상태는 이 방식으로
확인할 수 없어 전압 휴리스틱을 사용한다. USB 감지는 아이콘에만 적용하고
SOC 곡선 선택은 기존 전압 추정 상태를 유지한다.
이 표시는 외부 전원 연결 추정이며 실제 충전 여부/완료를 뜻하지 않는다.
- 1초 간격 원전압에 3샘플 중앙값 필터를 적용한다(SOC용 EMA와 별도).
- 직전 8개 필터값의 범위가 40mV 이내일 때만 그 평균을 기준으로 삼는다.
- +20mV 이상 상승은 연결 후보, -20mV 이하 하락은 분리 후보다.
- 후보 발생 후 변화량의 75% 이상이 3초간 유지되어야 상태를 확정한다.
- 급변 확정 뒤 5초간 재감지를 억제한다.
- 완만한 변화는 최근 30개 필터값의 앞 10개와 뒤 10개의 절사평균을 비교한다.
  각 구간에서 큰 값/작은 값 2개씩을 제외한다. 평균 차이가 +4mV면 연결,
  -4mV면 분리 방향이며 3회 연속 확인되면 상태에 반영한다(약 30초 이상 필요).
- 변화가 잡음 범위 안이면 마지막 상태를 유지한다. 상태 변경 시 추세 창을
  초기화해 이전 연결/분리 전압 변화가 반대 방향으로 재해석되는 것을 줄인다.
- 시작 상태는 미확인(오버레이 없음)이다. 처음부터 USB가 연결되어 있으면
  판별하지 못한다. 2.5초 초과 샘플 공백이나 비정상 전압은 미확인으로 초기화한다.

임계값은 실기 튜닝 전의 초기값이며 `src/battery_plug.h`에서 조정한다.
지속적인 부하 변화는 오검출될 수 있고, 완충 부근의 작은 전압 변화나
5초 이내 재연결은 놓칠 수 있다. 놓친 분리 이벤트는 표시를 남길 수 있다.
휴리스틱은 아이콘과 SOC 곡선 선택에 사용하며 충전 제어·저전압 종료에는 사용하지 않는다.

추정 연결 상태는 충전 곡선, 추정 분리는 방전 곡선을 선택한다. 미확인은
방전 곡선을 초기 기준으로 사용한다. 충전 곡선은 측정 전압에서 80mV를
차감해 기존 테이블에 넣는 초기 모델이다. 충전 전압 상승을 근사할 뿐
실측 보정이나 CC/CV 용량 적산은 아니다. 특히 CV 구간의 실제 SOC를
전압만으로 알 수 없으며, 이 모델은 충전 중 100%를 보장하지 않는다.

충전/방전 각각 마지막 표시 SOC를 RAM에 저장한다. 전환 시 들어갈 상태의
저장값을 나가는 상태의 마지막 SOC에 맞춰 재기준화하고, 새 곡선과의 차이를
오프셋으로 잡아 전환 샘플의 SOC를 그대로 유지한다. 이후 새 곡선을 따라가며
오프셋은 초당 0.02%p씩 0으로 줄이고, 표시 SOC 변화는 초당 최대 0.2%p로 제한한다.
긴 샘플 공백은 2초로 제한해 한 번에 최대 0.4%p만 변한다. 숫자에는 SOC 대신 전압을 표시하고, 이 SOC는 아이콘 채움에만 사용한다. 이력은 재부팅 시 초기화되며, 전압 기반 추정이므로 부하 변화에
따라 충전 중 소폭 감소/방전 중 소폭 증가할 수 있다.

실기 확인: USB 분리/연결 상태에서 전압과 표시 잔량을 비교하고, 100% 및
저전압 구간까지 충·방전하며 실측한다. 이번 변경은 장치에 자동 업로드하지 않는다.
